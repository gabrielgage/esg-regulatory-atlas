# PR 80 - Value-Chain Lane Simplification

Date: 2026-05-25  
Area: Product UX, value-chain triage, evidence planning

## Finding

The value-chain workspace exposed useful seed-record aggregation, but it still felt like a raw taxonomy page. Users had to interpret many value-chain tags and repeated chips before knowing which business question to start with.

## Resolution

- Reworked `/value-chain` around six practical business-exposure lanes: supplier due diligence, trade/imports, products/claims, portfolio/finance, own operations/governance and customer pressure.
- Added start questions, evidence prompts, first actions and suggested owners for each lane.
- Reduced repeated chip text and kept source-review cues compact.
- Preserved copyable summaries, filtered regulation handoffs, source-count context and legal caveats.

## Prevention Rule

Value-chain surfaces should remain lane-first. Add new raw tags only when they improve the six-lane triage model or when a dedicated lane is clearly warranted by user research. Do not expand `/value-chain` back into a dense list of all taxonomy tags.

## Legal/Trust Note

Value-chain lanes are seed intelligence and evidence-planning aids. They are not legal advice, official source verification, complete value-chain legal coverage or entity-specific applicability determinations.
