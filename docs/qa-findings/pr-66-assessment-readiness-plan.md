# PR #66 - Assessment Readiness Plan

## Finding

The assessment workflow generated useful indicative shortlists, but users still had to infer the next practical workplan from individual result cards. The expert review recommended making outputs more decision-ready without making legal applicability claims.

## Root Cause

Assessment results already carried reasons, missing facts, evidence, owners and next steps, but those signals were distributed across cards. There was no compact summary that translated the shortlist into threshold facts to check, first 30-day actions and likely owner functions.

## Resolution

- Added assessment readiness plan cards above the profile form and result list.
- Added threshold matrix row badges to assessment shortlist cards.
- Added threshold-sensitive record context to copied assessment summaries.
- Added smoke coverage so the readiness plan stays visible.

## Prevention Rule

When adding assessment signals, expose them as planning prompts with clear caveats. Do not turn shortlist ranking into legal applicability, compliance scope or confirmed deadline language.

## Caveat

Assessment readiness plans are indicative orientation outputs. They are not legal advice, tax advice, investment advice, assurance advice, source verification or entity-specific applicability determinations.
